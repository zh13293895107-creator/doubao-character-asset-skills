====================================================
  豆包角色资产技能包 · 离线安装说明
  （无需翻墙、无需联网、无需 GitHub）
====================================================

这个压缩包里包含 3 个豆包技能：

  1. photoreal-face-plate     人脸资产提示词（任意媒介 → 写实人脸定妆照）
  2. photoreal-garment-plate  服装资产提示词（白塑料假人 / 9:16 / 真实面料）
  3. character-asset-sheet    人物资产表提示词（左大头 + 无头全身正反 / 3:2）


----------------------------------------------------
一、Windows 安装（最简单）
----------------------------------------------------
1. 先把整个压缩包【解压】到任意文件夹
   （不要直接在压缩包窗口里双击，必须先解压）。

2. 进入解压后的文件夹，双击运行：

        双击安装-Windows.bat

3. 看到“完成：成功安装 3 个技能”后，
   完全退出并重新打开豆包（或新开一个会话）即可使用。

说明：
   - 安装是自动的，不需要手动找目录。
   - 如果之前装过同名技能，旧版会自动备份为
     “技能名.bak.时间戳”，再装新版，可随时回退。
   - 重复安装、反复安装都没有副作用。


----------------------------------------------------
二、macOS / Linux 安装
----------------------------------------------------
1. 解压压缩包，打开“终端”，进入解压后的文件夹。
2. 运行：

        bash install-offline.sh

3. 重新打开豆包（或新开会话）。


----------------------------------------------------
三、三个技能怎么用（可单独、可协同）
----------------------------------------------------
· 只要一张脸：上传人物图，说“做人脸资产 / 转写实 / face plate”。
· 只要一套衣服：上传人物图，说“做服装资产 / 衣服转写实”。
· 要完整角色资产表：上传头像 + 服装（或一张含脸和全身的图），
  说“做角色资产表 / 三视图 / turnaround”。

协同建议：先分别出人脸板、服装板确认无误，再合成三栏资产表。
三个技能输出的都是写实摄影级、可直接复制投喂图像模型的英文提示词，
统一锁定：哑光皮肤零油光、无影后期友好光、中灰无缝背景、
85mm（人脸/资产表）/ 50mm（服装）、35mm 细胶片颗粒。
技能默认只产出提示词；你明确说“出图”后才会调用生图。


----------------------------------------------------
四、卸载
----------------------------------------------------
删除豆包 .user_skills 目录下的三个同名文件夹即可：
  photoreal-face-plate / photoreal-garment-plate / character-asset-sheet

Windows 默认目录：
  %USERPROFILE%\AppData\Local\Doubao\User Data\Default\.doubao\agent_mode\workspace\.user_skills\
