# Character Asset Sheet — 高清角色资产表提示词

把头像参考与服装参考合成一张「左大头 + 右无头全身正反」的写实角色资产表英文提示词。产物是可直接复制投喂图像模型的完整 Prompt，不是分析报告。

## 不可违背的硬约束

1. **产物永远是照片**：photorealistic character asset sheet, photographed not rendered；Negative 穷举否定输入媒介。
2. **固定布局（三 figure、横版 3:2）**：
   - 左 1/3：正面大头照 head-and-shoulders close-up，脸充满画面，承载全部面部细节；
   - 中 1/3：无头全身正面（front view）；
   - 右 1/3：无头全身背面（back view）；
   - 整张图一个连续中灰无缝背景，无分割线、无框、无栏间空隙、无编号文字。
   - 出图参数强制 3:2 横版（如 3072×2048）。
3. **无头 = 取景裁切，不是断颈**：两个全身像的头在画面上边缘之外，顶边在领口上方、颈基处干净裁过；领口与肩线自然封顶，颈基皮肤连续无破损。严禁出现断颈、颈部断面、伤口、血腥、漂浮的头、白色塑料人台、ghost mannequin。
4. **只给正面与背面**：不出现侧面、四分之三侧面、任何额外 figure、动物或道具。
5. **三 figure 同一人同一衣**：肤色、年龄、身形、手一致；两个全身像的服装、颜色、磨损、配件、图案位置完全一致；大头照的脸与头像参考 feature for feature（同款眼、鼻、颌、发、配色），"the same face, not a similar face"。
6. **两张参考图各取所需**：`<<<FACE>>>` 只继承面部身份结构；`<<<GARMENT>>>` 只继承服装设计（廓形/剪裁/配色/图案/配件）。脸、服装都剥离媒介（画风、笔触、二次元光影、原画光照、背景）；只有一张参考图时两个标记指向同一张。
7. **真实材质、可制作**：服装为真实纤维/皮革/金属，非现实元素按真实裁缝与戏服逻辑落地（发光纹→刺绣、浮空件→真实支撑，规则同 photoreal-garment-plate 的转译表）。
8. **哑光皮肤、零油光**：pore-level 真实皮肤，matte，no oily sheen / no specular hotspots；粉底妆、腮红、二次元红晕不继承。
9. **后期友好光**：均匀柔和无影、无投影、无轮廓光/背光、无色偏、无环境反弹；白/灰背景干净，可直接抠图重打光。
10. **提示词语言为英文**；与用户的中文沟通可保留中文。所有特征必须基于实际读图，看不清的结构按最常见成衣/人体常识中性处理，不编造。

## 工作流程

### 1. 读图（必须实际打开）

- 本地路径直接 `Read`；URL 先下载（PowerShell：`Invoke-WebRequest -Uri "<url>" -OutFile "<local>"`）再读。
- 至少读两类信息：**头像**（脸，优先正面清晰图）与**服装**（全身/半身穿着图）。同一张图兼任时，脸和服装都从该图取。
- 面部或服装细节不清时放大重看、分区裁剪（领口、门襟、袖口、腰头、后背、面料、鞋底）。

### 2. 分别判定媒介

头像与服装各自判定五类：illustrated（动漫/立绘/插画）/ painted（油画/水彩/古典绘画）/ rendered（3D/CG）/ photo（真人照片）/ sculpted（手办/雕塑）。从 `references/sheet-template.md`「媒介适配段」取对应隔离措辞与否定词；媒介不同则组合两套否定。

### 3. 提取面部身份（喂给左栏）

逐项观察：表观年龄、性别、族裔、脸型、额头、颊、下颌、下巴、眼型/眼距/眼色/眼睑、眉、鼻、唇、肤色、发色发质发流发际线、胡须。按 photoreal-face-plate 的标准转为写实描述，不继承夸张大眼与腮红。

### 4. 逐件提取服装（喂给中/右栏）

由外到内逐件过：品类、廓形、长度、领、肩袖、门襟、结构细节、真实面料（纤维+织法）、颜色、图案与实现工艺、做旧磨损、配件（帽/腰带/围巾/手套/耳机/首饰/包）、鞋袜。

**背面信息规则（关键）**：
- 参考图展示了背面：逐件照写（后领、后片、后背印花、后腰、后袋、后衩、鞋跟、饰品后侧）。
- 参考图只有正面：背面按同类成衣最常见结构中性补全（后片净色、无印花、标准后领/后腰/后袋），**禁止在背面编造图案、logo、特殊装饰**；并在给用户的中文说明里注明"背面为常规推断"。
- 正面已有磨损/污渍时，只在可见侧描述；泥点等按自然接触补到合理位置（如鞋头正面+鞋跟后侧）。
- 非现实服装元素按模板内《奇幻转译规则》落地。

### 5. 组装提示词

读取 `references/sheet-template.md`，按 14 段顺序组装：Opening → Face Reference → Garment Reference → Layout → Close-up → Headless Front → Headless Back → Continuity → Wardrobe → Lighting → Background → Lens → Skin → Technical + Negative。

### 6. 自检后交付

逐条过模板末尾自检清单；完整提示词放一个代码块。用户若要求正/反面拆成两张独立竖图时，分别产出两张 2:3 竖版提示词（正面版：左大头+右无头正面；反面版：无头背面单栏），并在文中注明。

## 与用户的边界

- 只产出提示词，不调用生图工具，除非用户明确要求；出图时画幅强制 3:2。
- 换服装/换配色/改姿势/加视图只改对应段，锁定段原样保留。
- 不复制真实品牌 Logo 与可识别制服标识；真人头像参考不输出姓名身份。
- 全身像姿态默认中性站立（正面双臂微张露服装，背面自然垂臂露后背）；用户指定的角色习惯姿势（如手缩进袖口）可写入正面，背面仍保持中性。
